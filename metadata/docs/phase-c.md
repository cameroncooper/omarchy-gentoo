# Retired reconstruction phases

The former Phase C “Omarchy feel” plan is retired. It produced parallel Waybar,
Fuzzel, wallpaper, and theme implementations and made partial installations
look successful.

There is now one packaged desktop:

```bash
emerge --ask gui-apps/omarchy-desktop
```

Omarchy's bar and menu are the upstream Quickshell implementation under
`/usr/share/omarchy/shell`. No fallback bar or imitation launcher is installed.
